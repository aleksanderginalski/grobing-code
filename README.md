# grobing-code

Kod aplikacji **Grobing** (Flutter, Android, local-first). Repo jest **celowo prawie puste** w dniu
materializacji: projekt Fluttera tworzy agent `dev` w zadaniu
`grobing-vault/backlog/issues/ISSUE-002-bootstrap-code-repo.md` — świeżym `flutter create` na
przypiętej wersji SDK, **nie** kopią innego projektu.

- Agenci i reguły: `../grobing-agents/` (tam otwierasz sesje, `/pm`).
- Dokumentacja i decyzje: `../grobing-vault/`.
- ⚠️ **Żadnych danych rodziny w tym repo** — ani bazy, ani kopii, ani eksportów, ani zdjęć prawdziwych
  osób. Dane żyją w aplikacji na telefonie. `.gitignore` obok to pierwsza linia obrony, nie jedyna.
